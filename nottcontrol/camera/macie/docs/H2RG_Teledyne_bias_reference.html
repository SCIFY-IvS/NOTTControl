H2RG detector bias reference — Teledyne acceptance vs NOTT (working)

Slow mode, cold ASIC (<40 K). Registers are ASIC addresses (MSAC / Manual Command: hXXXX). Values in 0xXXXX are full 16-bit MCD register writes unless noted. Printed: August 2026.

Summary: All Teledyne acceptance biases match NOTT bench values except VBiasGate1 — use h6004 = B580 (2.05 V) instead of B600 (2.30 V).

  • Vout: Teledyne acceptance “Vout = 2.0 V” is an output-level specification in the test report, not a separate h6000 detector bias DAC. No register change required for NOTT.
  • VDD / VDDA at 3.32 V: DAC quantisation gives 87FF ≈ 3.30 V actual; 87E3 ≈ 3.25 V. Teledyne table often lists 3.32 V as the nominal target.
  • VRefMain h602C = 8400: SIDECAR main reference (~1.30 V at the DAC). Required for valid MSAC reset/readout (values like 8334 produced all-zero reset frames in NOTT tests).
  • Verify in MSAC: After Init, use Telemetry → Calibrated Voltage (see Readme.MD telemetry procedure; h6180 = 2232 for cal mode).
  • MCD / cfg files: Detector biases live in HxRG_Teledyne.mcd; overrides in teledyne_cold_slow.cfg as reg_* keys.
  • Odd registers (h6001, h6003, …): current/strength pairs — leave at MCD defaults unless Teledyne specifies otherwise.
